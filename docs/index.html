01 · Script + Claude skill + LLM prompt

MBR Assistant

For roles:Partner / Channel ManagersAlliancesPartner Marketing
Problem to solve: rebuilding JMP and MBR production around AI to cut the time.

Solution: a script cleans the partner data and calculates every KPI; AI drafts the one-page review; the partner manager checks and shares it.

Results: about 60% less JMP/MBR production time across 19 ISV partners (AWS Canada partner program); numbers are always calculated, never generated.

Why it matters: partner managers spend their time with partners instead of in spreadsheets, and every review is consistent and verifiable.

03 · Scenario model

ROI Metric Tree

For roles:Sales & Marketing leadersPartner DevelopmentRevenue Operations
Problem to solve: an AI investment case with a metric tree, three scenarios, break-even adoption and a pass/fail gate.

Solution: one assumptions file produces the metric tree, three scenarios, break-even adoption, a sensitivity grid and a go / no-go gate.

Results: an 80-seat rollout fails (−8.5% ROI); the same tool for 30 power users passes (+38.6% ROI, 29.8-point safety margin).

Why it matters: turns “AI saves time” into a profit-and-loss case a VP or CFO can approve, rescope or stop.

How I build

The same five rules run through every prototype.

Calculate, then generateScripts own the numbers. Models write the story.
Name the solution pathWhat the human, the AI and the system each do.
Measure against a baselineOnly P&L-linked value counts; review time is a cost.
Gate decisionsForbidden zone, readiness, value, margin above break-even.
Humans decideEvery output is a draft for review.
