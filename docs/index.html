How I build

The same five rules run through every prototype.

Calculate, then generateScripts own the numbers. Models write the story.
Name the solution pathWhat the human, the AI and the system each do.
Measure against a baselineOnly P&L-linked value counts; review time is a cost.
Gate decisionsForbidden zone, readiness, value, margin above break-even.
Humans decideEvery output is a draft for review.
All company names and data in these prototypes are fictional. Results from past roles are from my CV; no employer or partner data is included. © 2026 Oscar Farrera · MIT License.
