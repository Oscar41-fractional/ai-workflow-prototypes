Score and rank

  • Score = Value x Ready (maximum 25), then adjusted: +2 if it creates a reusable pattern other teams can copy; -4 if the team has low capacity for change; -3 if mistakes are hard to undo.
  • Requests are ranked by score; a tie goes to the higher gross value.
  • Before scoring, two gates remove requests: the forbidden zone (a legal or policy rule reserves the decision for a human) and the readiness zone (data readiness or process readiness below 3 means "fix this first").
  • Data class: green = public, amber = internal, red = personal, financial, legal or regulated. Red data plus mistakes that are hard to undo means a human approves every output.

Hours and gross value

  • Hours/yr = volume per month x minutes saved per item / 60 x 12. Volume comes from the team's system (tickets, quotes, contracts per month); minutes saved come from a short time study of the task today versus with AI.
  • Loaded cost is the hourly cost of the people doing the work: salary plus benefits and overhead, from Finance.
  • Gross value/yr = Hours/yr x loaded cost. It is gross because not every saved hour becomes money; prototype 03 applies a realization factor to get the value that actually reaches the P&L.

Decision briefs

1. Partner business review drafts (T-01, Partner Development)

  • Problem: Each monthly partner review takes about 3 hours to assemble from spreadsheets
  • Requested by: Partner Marketing Lead
  • Size of prize: 40 items/month x 120 min saved / 60 x 12 = 960 hours/yr x $65/h loaded cost = $62,400 gross/yr (before realization)
  • Why Value 4, Ready 4: data readiness 4/5, process readiness 4/5, data class amber, change capacity high
  • Scoring: value 4 x readiness 4 = 16; creates a reusable pattern (+2) -> 18
  • Decision: Build business case now

2. Campaign brief to asset drafts (T-03, Marketing)

  • Problem: Each campaign needs 12 asset variants written by hand
  • Requested by: Content Marketing Lead
  • Size of prize: 60 items/month x 45 min saved / 60 x 12 = 540 hours/yr x $60/h loaded cost = $32,400 gross/yr (before realization)
  • Why Value 3, Ready 5: data readiness 5/5, process readiness 4/5, data class green, change capacity high
  • Scoring: value 3 x readiness 5 = 15; creates a reusable pattern (+2) -> 17
  • Decision: Small pilot if capacity allows

3. Inbound lead research and routing (T-02, Sales)

  • Problem: New inbound leads wait up to a day to be researched and routed to the right rep
  • Requested by: Sales Operations Manager
  • Size of prize: 900 items/month x 6 min saved / 60 x 12 = 1,080 hours/yr x $55/h loaded cost = $59,400 gross/yr (before realization)
  • Why Value 4, Ready 4: data readiness 4/5, process readiness 4/5, data class amber, change capacity medium
  • Scoring: value 4 x readiness 4 = 16; no adjustments -> 16
  • Decision: Build business case now

4. Account research before first call (T-04, Business Development)

  • Problem: Reps spend 15 minutes per account across many sources before a first call
  • Requested by: BDR Team Lead
  • Size of prize: 300 items/month x 15 min saved / 60 x 12 = 900 hours/yr x $50/h loaded cost = $45,000 gross/yr (before realization)
  • Why Value 4, Ready 3: data readiness 3/5, process readiness 3/5, data class amber, change capacity medium
  • Scoring: value 4 x readiness 3 = 12; creates a reusable pattern (+2) -> 14
  • Decision: Fix readiness, re-score in 90 days

5. MDF claim proof-of-execution pre-check (T-05, Partner Development)

  • Problem: Proof-of-execution files for each MDF claim are checked by hand against the pre-approval
  • Requested by: Channel Programs Manager
  • Size of prize: 120 items/month x 20 min saved / 60 x 12 = 480 hours/yr x $65/h loaded cost = $31,200 gross/yr (before realization)
  • Why Value 4, Ready 3: data readiness 3/5, process readiness 4/5, data class red, change capacity medium
  • Scoring: value 4 x readiness 3 = 12; errors are hard to reverse (-3); red data + irreversible: human approval on every output -> 9
  • Decision: Fix readiness, re-score in 90 days
